## État pour la Brique 0

La gouvernance multi-tenant réelle sera introduite à partir de la Brique 1 (schéma PostgreSQL avec `tenant_id`, `country_code`, `data_classification`) et formalisée pleinement en Brique 8 (Audit + Human-in-the-loop).
